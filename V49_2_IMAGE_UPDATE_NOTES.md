# VEC V49.2 — Complete Product Image Update

This package is a complete V49.2 website archive, not a patch.

## Product image correction
- Includes the nine supplied activity-kit and interactive-kit images in `public/assets/products/`.
- The five curated product cards use the bundled VEC product photography.
- Sanity CMS can continue to supply product copy, stage/status, and other text fields.
- Stale CMS `imageUrl` and `galleryImages` fields can no longer override the curated local product images.
- No official VEC logo artwork has been recreated or altered.

## Install
1. Extract this ZIP.
2. Open the extracted `VEC_Production_Website_V49_2` folder.
3. Run `npm install` only if dependencies are not already installed.
4. Run `npm run dev` to preview, or `npm run build` to test a production build.

## Validation boundary
The archive contents and product-image references were checked. A full production build was not run in this packaging step.
